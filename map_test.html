WordPress Map Embed Examples

This box represents your standard WordPress page content area, which is usually restricted to a certain width (e.g., 800px).

Method 1: Standard 100% Container Width

This map fills 100% of the container it is placed inside. You can copy just the iframe tag and paste it into a WordPress Custom HTML block, changing the width attribute to 100%.

Method 2: Forced Edge-to-Edge Width (100vw)

If your WordPress theme keeps the map trapped in a narrow column, apply the .map-force-full-width CSS class. Scroll down to see it break out of this white box and stretch across the entire screen.

How to use this in WordPress:

  1. Go to Google Maps, find your location, click "Share," and choose "Embed a map."
  2. Copy the HTML provided by Google.
  3. In WordPress, add a "Custom HTML" block to your page.
  4. Paste the iframe code.
  5. Change the width="600" (or whatever number is there) to width="100%".
  6. If it's still not full width of the screen, you'll need to use the CSS trick from Method 2 in your theme's customizer.
